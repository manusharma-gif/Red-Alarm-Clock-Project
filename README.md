# Red-Alarm-Clock-Project
Red Alarm Clock is a bold red, easy-to-use alarm app that runs in any browser, with no sign-up. See the live clock, set alarms with a name and repeat days, choose from six ringtones or upload your own, and stop or snooze when it rings. Works on phone and desktop.
Project Name: Red Alarm Clock Project

Features: Set alarms, custom ringtones, snooze function, etc.

Tech Stack: Built with HTML5, CSS3, vanilla JavaScript, SVG, Web Audio API and localStorage.
